# Hebrides Cyber — Pricing Page Content

Transparent pricing for predictable security. Choose a one-off audit or a monthly plan for continuous protection.

## One-off Audits

**Small Website Audit — £300**
Automated scan, headers & TLS checks, dependency scan, 1-page Security Score, remediation checklist.

**Standard Web App Audit — £800**
OWASP Top 10 manual testing, API testing, auth/session checks, dependency scan, 8–12 page report, 1 hour remediation call.

**Full SaaS Audit — £1,800**
Full manual pen test, CI/CD review, cloud permissions review, RLS/database checks, 20+ page report, 2 hours remediation support.

## Monthly Subscriptions (Security Score)

**Basic — £20/month**
Weekly automated scans, monthly Security Score email, critical alerts.

**Pro — £35/month**
Everything in Basic + dependency monitoring, Slack alerts, quarterly manual review.

**Agency — £75/month**
Multi-site monitoring, white-label PDF reports, priority support, monthly manual review.

## Add-ons

- On-site or remote pen test (priced per engagement)
- CI/CD hardening workshop — £300 flat
- Emergency incident response — quoted on request

## Payment & Terms

- Monthly plans billed via Stripe.
- One-off audits invoiced 50% upfront, remainder on delivery.
- Standard NDA included with every engagement.
- SLA for Pro/Agency plans: 24-hour critical alert response.
