# Hebrides Cyber — Branding & Logo Concept

## Brand name & domain
Hebrides Cyber — hebridescyber.co.uk

## Tagline
Developer-grade security from the Isle of Lewis

## Tone & voice
- Professional, direct, technical but accessible to non-technical owners.
- Plain English for executive summaries; technical appendices for engineers.
- Locality (Hebrides) used as trust and story, not limitation.

## Color palette
| Name | Hex | Use |
|---|---|---|
| Deep Atlantic Blue | #0B3D5B | Primary, trust, maritime heritage |
| Heather Purple | #6B4C7A | Hebridean landscape accent |
| Seafoam Accent | #7FD3C7 | Highlights, CTAs |
| Neutral Slate Light | #F6F7F9 | Backgrounds |
| Neutral Slate Dark | #2F3A44 | Text |

## Typography
- Heading: Inter or Poppins (modern, geometric)
- Body: Roboto or Source Sans Pro (readable, developer-friendly)

## Logo concept
**Mark:** A simplified shield outline formed from two stylised waves — left wave represents the Hebridean sea, right wave forms a code bracket `}`, a subtle developer cue.

**Wordmark:** "Hebrides" in bold, "Cyber" in medium weight, tagline set beneath in small caps.

**Variants needed:**
- Full horizontal logo (header/nav)
- Stacked logo (social avatars, favicon source)
- Favicon (shield mark only, simplified to work at 16–32px)
- Monochrome / single-color version (for print, watermarks, invoices)

## Iconography & imagery
- Drone/landscape hero photos of Lewis for local-facing pages.
- Minimal, schematic security icons for service pages: shield, magnifying glass, pipeline, cloud, lock.
- Consistent muted Deep Atlantic Blue overlay on photography for brand cohesion.
