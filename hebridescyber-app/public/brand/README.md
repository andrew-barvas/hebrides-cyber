# Brand assets

Hebrides Cyber logo + icon, derived from `public/favicon.svg` / `src/app/icon.svg`
(a glowing neon-green `>` terminal prompt on near-black).

| File | Use |
|---|---|
| `hebrides-icon.svg` / `hebrides-icon-512.png` / `hebrides-icon-1024.png` | Square app icon — Stripe brand icon, product images, avatars, favicons |
| `hebrides-logo-light.svg` / `hebrides-logo-light.png` | Horizontal logo for **light** backgrounds (black `HEBRIDES` + green `CYBER`) — invoices, Stripe Checkout, docs on white |
| `hebrides-logo-dark.svg` / `hebrides-logo-dark.png` | Horizontal logo for **dark** backgrounds (white `HEBRIDES` + neon green `CYBER`), transparent |

## Palette

| Token | Hex | Use |
|---|---|---|
| Black (brand) | `#070B14` | backgrounds; wordmark on light |
| Neon green | `#39FFC0` | the mark; accent on dark |
| Deep green | `#067A5B` | accent / wordmark on light surfaces (better contrast than neon) |

PNGs are rendered from the SVGs; re-render with the SVG as source if you change them.
