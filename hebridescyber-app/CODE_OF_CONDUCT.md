# Code of Conduct

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).

## Our Pledge

We as contributors and maintainers pledge to make participation in this project
a harassment-free experience for everyone, regardless of experience level,
background, or identity.

## Our Standards

- Be respectful and constructive in code review and issue discussions.
- No harassment, discrimination, or personal attacks.
- Assume good faith; disagree on technical merits, not people.

## Scope

This applies to all project spaces: the repository, issue tracker, and any
associated community channels.

## Enforcement

Report unacceptable behaviour to the project maintainer (see README for contact).
